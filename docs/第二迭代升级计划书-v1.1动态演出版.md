## 4. 模块详细设计

### 4.1 S1 场景动态化

**4.1.1 Canvas 粒子层（新建 js/fx.js）**
全屏 fixed Canvas（pointer-events:none），按 `html[data-scene]` 切换粒子配方：

| scene | 场景 | 粒子配方 | 数量上限(桌面/移动) |
|---|---|---|---|
| 0 | 封面 | 灵尘（增强，替换现有 #motes DOM 粒子） | 140/50 |
| 1 | 纹谱阁·深夜 | 油灯尘埃（金色微粒极缓漂移） | 40/16 |
| 2 | 灵兽苑·清晨 | 晨雾光尘 + 上浮灵气泡 | 80/30 |
| 3 | 测纹处·日暮 | 流萤 3–5 只（明灭 + 曲线游动） | 5/3 |
| 4 | 分纹台·正午 | 烈日浮尘 | 60/20 |
| 5 | 夜枭谷·月夜 | 枯叶缓落 | 20/8 |
| 6 | 渡劫 | 风卷残尘（雨丝仍归 CSS） | 40/15 |

要点：rAF 循环、DPR 适配、`document.hidden` 暂停、`prefers-reduced-motion` 完全不建循环、淡入淡出；现有 #motes 职责迁入 Canvas（CSS 层留极淡兜底或移除，实施时二选一并记录）。

**4.1.2 氛围层动态（CSS）**
- `.scene-clouds` / `.scene-far`：20–60s 缓慢漂移（translateX 极小幅度）+ opacity 呼吸（幅度 ≤0.06），参数经 CSS 自定义属性按 scene 区分；
- scene1 油灯、scene3 灯笼：烛火摇曳（scale/亮度不规则 flicker，3–6s）+ 径向光照范围轻晃；
- scene5 月光呼吸；scene6 雷闪体系已有，不重复。

**4.1.3 分层视差**
- 指针视差（现有 --px/--py）扩展为分层：远山 0.6 / 云海 0.8 / 近景 1.2 系数（translate3d + calc）；
- 主舞台滚动时背景缓移（系数 0.3）；仅桌面 `pointer:fine`；reduced-motion 停用。

### 4.2 S2 闯关演出化

**4.2.1 聚灵槽（答题=轻战斗）**
- 历练/试炼题目界面显示"聚灵槽"（按当前章题目数分格）；每题首答正确点亮一格（金色上涌 0.5s）；答错触发"反噬"：题卡 250ms 微震 + 墨渍扩散 600ms + 低闷鼓；
- 状态：cur 内计数，进章/重玩重置；错题本重做不计槽但保留轻光效；Boss 关不显示。

**4.2.2 破境三段式演出（≤2.8s，点击/Esc/Enter 可跳过；reduced-motion 播 0.4s 简版）**
1. 聚气 0.9s：压暗 + 粒子向心汇聚（现有粒子函数参数化复用）；
2. 天光 0.8s：金色光柱 + 双冲击波 + 轻微 zoom 震屏；
3. 铭刻 1.0s：朱砂大印 + 境界文字拓印浮现 + 亮度恢复。

**Boss 渡劫版**：雷云压顶暗化 → 三次雷闪逐次增强（复用 flashHit + 屏震）→ 金光甘霖 + "渡"字印。改动限 breakthrough/#fx 渲染层与 CSS，不改 finishLevel 时序。

**4.2.3 通用**：新增 .shake / .zoom-pulse 工具类（reduced-motion 无位移）。

### 4.3 S3 山河路线图（重做侧栏 roadmap）

- 节点间连接线：内联 SVG 弯曲路径（水墨描边）；已通关段金色、当前段脉动；
- 节点三态：done（朱印"过"+金边+光晕呼吸）/ current（金色脉动光圈+微浮动 2s 循环）/ locked（灰暗+云雾遮罩）；

### 4.4 S4 手感与氛围

- 自定义光标：桌面 pointer:fine 启用金色灵纹笔尖（内联 SVG data URI），文本输入区保留文本光标；
- 点击涟漪：墨色涟漪 400ms 消散，节流 300ms；
- 环境音：sound.js 增 `App.setSceneAudio(n)`——WebAudio 滤波噪声合成极轻底噪（scene5 夜风、scene6 风雨为主，其余极轻或静音），1.5s 交叉淡入淡出，跟随主开关与首点策略，音量 ≤-28dB，若听感廉价宁缺毋滥；
- 境界 HUD：侧栏境界文字金色流光 shimmer；破境后"拓印浮现"一次。

### 4.5 E 立绘槽位（只搭结构，不画插画）

- 非旁白说话人对话左侧加 `.portrait-slot`：当前为"墨色剪影圆盘 + 单字朱印"占位 + 3.5s 呼吸浮动（reduced-motion 停）；
- 代码注释写明对接规范：未来插画放 `assets/portraits/<who>.svg`（512×512 透明底、墨金朱风格），引擎按路径自动生效；
- 窄屏 <640px 缩为小型圆章，全程无布局抖动。

形象：内联简笔 SVG（viewBox 96×96、单色剪影+金线点缀），随 stage 用形态/滤镜区分。

**4.6.2 分阶练习题库（GAME_DATA.petQuests）——难度随阶段上升**

每宠 3 组 × 每组 ≥4 题 = **至少 72 道新题**（6 宠 × 12）：

| 题组 | 开放条件 | 难度定位 | 示例方向（以传声灵雀为例） |
|---|---|---|---|
| 入门 | 获得宠物即开放 | 本章知识点直接应用，贴近讲解例题 | `print("我会把路走回来")` 输出什么 |
| 进阶 | stage ≥1 | 易错点/小坑混合：引号嵌套、字符串+数字报错、range 含头不含尾、缩进归属 | 指出 `print("18"+1)` 会怎样 |
| 登峰 | stage ≥2 | 综合/找错/陷阱：多步预测、故意写错定位、跨知识点组合 | 给一段混合代码，找错并预测输出 |

- 题型复用现有 schema：选择题（可带 code）与 C 型补全 fill；
- 每题 Python 语义必须经**本机 python 3.14 实测**后再定答案；文案沿用修仙口吻；不与主线题目重复；
- Boss 宠 pet_jiao 题库 = 全卷综合，登峰组为最高难度。

**4.6.3 获取 / 成长 / 进化规则（数值版）**

| 行为 | 灵石 | 宠物成长 | 备注 |
|---|---|---|---|
| 通关某章（首次） | — | 该章宠 +1 | 同时孵化灵卵 + 获得灵器 |
| 历练/试炼/操练每题首答正确 | +1 | 操练题另 +1 | 同题不重复计 |
| 完成一次完整操练（3 题全对） | — | +1 | 答错可重试 |
| 该章试炼零失误通关 | — | +2 | |
| 错题本温习答对 1 题 | — | 主宠 +1 | 主宠=最新通关章对应宠 |
| **进化 stage0→1** | — | 需累计 growth≥5 | **且入门操练通关**（3 题全对） |
| **进化 stage1→2** | — | 需累计 growth≥12 | **且进阶操练通关** |

> 设计意图：想进化必须先证明掌握当前难度——练习是唯一主渠道，越往后练得越难（登峰组仅 stage2 开放，用于复习与刷分）。growth 只增不减，超阈值显示满。

**4.6.4 操练会话流程**
行囊面板 → 灵宠"操练" → 从当前可练最高题组随机抽 3 题（stage0 只能入门；stage1 优先进阶；stage2 优先登峰）→ 复用主线答题渲染/判定（含 fill）→ 答错 hint 可重试 → 3 题全对 = 通关（弹"灵光圆满"小结 + 成长结算）→ 达门槛先播升阶演出（金色光效 + 新合成琶音 sfx 'levelup'）。题组面板标注 已通/未通/未开放；已通可重复操练（重抽题防刷单题）。
