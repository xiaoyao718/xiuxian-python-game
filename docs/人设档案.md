# 修仙学 Python · 人设档案（基准 v1）

> **用途**：所有 AI 会话、剧情写作、像素/立绘美术产出**一律以本档案为基准**，防止人设漂移。
> **配套**：`docs/第三迭代-AI提示词包.md` 0.6 节（人设卡模板 / 像素提示词 / 立绘提示词 / 台词人格提示词）。

## 1. 视觉设计系统（全角色通用）

| 项 | 规范 |
|---|---|
| 主调色板 | 墨黑 #1a1712 / 纸白 #e9e1cc / 金 #c8a44b / 朱 #a93a2d |
| 角色专属色 | 见各角色卡 hue 字段（低饱和，取自水墨体系） |

| 纹样词典 | 旧笔/残页（林慕·仙典）、云纹/鹤纹（林韬）、玉佩暗纹（周显）、官袍补纹（章管事）、赤目铁毛（妖狼王）、灯暖（夜巡二人组） |

## 2. 角色卡

### 林慕（主角）
- **身份**：17 岁，云水城林家旁支，北辰宗外门杂役；曾为通纹天才，灵台碎裂三年。
- **外观**：灰布旧袍洗得发白，发髻散乱几缕碎发，清瘦带倔，常垂眸抬眼。
- **性格**：坚忍 / 倔强 / 记恩也记仇；破绽点：嘴上逞强、肚子会饿（食堂梗）。
- **口头禅**（低语）：我会把路走回来。
- **专属**：hue 素青 #8fa8b8；glyph「慕」；纹样 旧笔/残页。
- **剧情位**：贯穿第一卷；Boss 渡劫亲手写抗雷法诀。
- **像素要点**：灰袍+腰间旧笔+散碎发丝。

### 仙典（Python 仙典器灵）
- **身份**：一页泛黄残页的器灵，凡人算术书所化；林慕的引路人。
- **外观**：悬浮残页，纸面金色灵纹流转（可作非像素光效形态）。
- **性格**：老成 / 毒舌 / 惜才 / 谜语人（只埋伏笔不揭答案）。
- **口头禅**：急什么？
- **专属**：hue 金 #c8a44b；glyph「典」。
- **剧情位**：F1/F6 伏笔本体——"上一任持有者"与"若灵台碎…可问心"。

### 林韬（外门反派 · lv1 夜嘲 / lv2 灵兽苑）
- **身份**：外门锦衣弟子，骑鹤佩玉，专挑软柿子捏。
- **外观**：锦袍高领、扬下巴，发冠端正，眉眼间满是倨傲。
- **性格**：嘴硬 / 心慌 / 欺软怕硬；破绽点：嘴硬但会偷偷服软（"还欠我一句没还呢，可别死在这儿"）。
- **口头禅**：哟，废物还醒着？
- **专属**：hue 浮金 #c8a44b；glyph「韬」；纹样 云纹/鹤纹。
- **剧情位**：lv1 夜嘲、lv2 灵兽苑两度登场；rivalWin 变体=嘴硬露怯。
- **像素要点**：锦袍高领+扬颏+腰佩玉。

### 周显（内门反派 · lv4 分纹台）
- **身份**：内门劲装弟子；三年前秘境中林慕救过他的命。
- **外观**：深色劲装、抱臂而立，皮笑肉不笑，眼神阴冷带一丝闪躲。
- **性格**：刻薄 / 忌惮 / 内愧不敢认；破绽点：欠着林慕一条命。
- **口头禅**：（冷笑）废人，也配谈判断？
- **专属**：hue 玄青 #4a5a6a；glyph「显」；纹样 玉佩/暗纹。
- **剧情位**：lv4 分纹台刁难；rivalWin 变体=忌惮收敛。
- **像素要点**：劲装束袖+玉佩+侧身抱臂。

### 章管事（外门执事 · lv3 测纹处）
- **身份**：测纹处执事，青灰官袍、山羊胡，管纹试与名册。
- **外观**：官帽官袍，眼皮常抬不抬，翻名册的手指很稳。
- **性格**：外冷 / 内正 / 公事公办；破绽点：丙等令是他给的（暗中给机会）。
- **口头禅**：名字。修为。一样样报——报错一个字，明年再来。
- **专属**：hue 官褐 #8a6f52；glyph「章」；纹样 官袍补纹。
- **剧情位**：lv3；F3 伏笔（名册涂墨只余"林"字）——与林家旧事有关。
- **像素要点**：山羊胡+官帽+手持名册。

### 妖狼王（lv5 夜枭谷 Boss 级敌手）
- **身份**：夜枭谷狼王，狼群成灾之源；曾让内门弟子铩羽。
- **外观**：黑毛如铁、赤目幽光，体魄比寻常妖狼大一圈。
- **性格**：凶蛮 / 孤傲；破绽点：被围剿的悲凉（守着自己的谷）。
- **专属**：hue 墨赤 #8a3a30；glyph「狼」。
- **剧情位**：lv5 夜枭谷；战败退场台词要"服而不屈"。
- **像素要点**：赤目+立耳+颈毛炸起。

### 夜巡二人组（lv1 反派对决默认敌方 · D6 待终审）
- **身份**：外门巡夜杂役，一胖一瘦，灯笼为伴。
- **外观**：灰暗杂役服，胖的提灯、瘦的扛棍，总凑在一起咬耳朵。
- **性格**：怂 / 欺软怕硬 / 一捧一逗；破绽点：风大一点就跑。
- **口头禅**：（胖）抄纹的还没睡？（瘦）人家可是"通"纹天才——通到擦灰。
- **专属**：hue 灯暖 #b98a5a；glyph「巡」。
- **剧情位**：呼应第一章"窗外两个笑你的人"；rivalWin 变体=绕道走。
- **像素要点**：一胖一瘦体型差+一盏灯笼。

### 小师妹（伏笔人物 · 本卷不登场）
- **身份**：林慕儿时同门，如今在内门；笔记本记满 Python 心得。
- **关联伏笔**：F4 斗笠人影（腰铃似白鹤）、F7 竹简"他醒了，落款一点墨"。
- **定位**：第二卷「笔记本秘境」关键人物；本期只埋不收。

## 4. 写作红线（AI 产出必须遵守）

1. 修仙白话风，短句有力；禁止现代网络用语、禁止英文梗直译。
2. 反派不洗白、只立体；主线"努力打脸"的爽感不塌。
3. 伏笔只埋不收：本卷所有 F 系列伏笔一律不解释，谜底留给第二卷。
4. 称呼与口头禅对照档案，任何人设改动先更本档案再写内容。
5. 林慕可以逞强，但不可以油腻；仙典可以毒舌，但不可以贬低学习本身。
