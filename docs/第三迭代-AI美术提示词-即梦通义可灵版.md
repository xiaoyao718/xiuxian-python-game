## 0. 通用基座（每条图前都带，保证 8 张风格统一）

```
影视级修仙动画场景概念图，国风写实水墨融合：低饱和墨青金配色，宣纸颗粒质感，
丁达尔体积光，远景水墨晕染群山与云海，近景古建木构细节真实（青瓦飞檐/窗棂/
纸灯笼/石阶青苔），暗部有层次不死黑，构图左密右疏：右侧 1/3 保持较暗简洁
（供游戏界面文字显示），画面无人物无文字无水印，电影宽银幕构图，16:9，超清细节。
```

通用负向词（每张追加）：
`文字，水印，签名，现代物品，英文，卡通塑料感，高饱和艳色，杂乱噪点，人物特写`

## 1. 场景（每章一张 + 封面 + 完结；16:9 输出）

### 1.1 纹谱阁·深夜（lv1 · data-scene 1）
```
室内仰角机位。破败藏纹楼阁：一张堆满废弃灵纹符纸的长案，一盏油灯（灯如豆，暖金火苗），
案角一页泛黄残纸微微泛起金色灵光（全图唯一亮点）；满地纸堆影子拉长，尘埃悬浮在灯柱光路里；
窗外冷月，远处宗门夜巡灯火如星点。氛围：压抑三年中的一点火种。主色：墨褐+灯暖金；光线：单点暖光。
```

### 1.2 灵兽苑·清晨（lv2 · data-scene 2）
```
室外清晨薄雾，低机位平视。木栅灵兽苑：白鹤单腿立在晨雾里梳羽，草料堆、木桶、湿泥地面，
晨光从左侧低角度斜穿雾气形成 3-4 道光柱，露珠反光；远山淡青隐在雾后。氛围：万物初醒的宁静。
主色：青灰+晨光暖白；光线：柔和侧逆光。
```

### 1.3 测纹处·日暮（lv3 · data-scene 3）
```
宗门青石广场纵深构图。测纹长队（剪影）从近景排向远处执事案台，案上朱红测纹令牌微反光；
日暮暖橙低斜光把影子拉长，檐角两盏纸灯笼刚亮，远处钟楼与山门剪影。氛围：期待与紧张交织的黄昏。
主色：暮橙+墨青；光线：低角度暖逆光。
```

### 1.4 分纹台·正午（lv4 · data-scene 4）
```
大场面中远景略俯。中央圆形分纹石台，金色光柱冲天、稳稳停在半空，四周层层叠叠围观人群剪影；
烈日当顶，石台与人群投下明确阴影节奏，檐旗微扬。氛围：万众屏息的胜负时刻。
主色：烈日金白+墨色剪影；光线：正午顶光，高反差。
```

### 1.5 夜枭谷·月夜（lv5 · data-scene 5）
```
月夜幽谷中景。惨白月光从谷口斜入，谷口立残破石碑；枯树乱石嶙峋，远处几点幽绿狼眼反光，
风卷枯叶贴地掠过，雾气沿谷底缓慢流动。氛围：肃杀中一人独行的孤勇。
主色：冷蓝墨+月光白；光线：冷月光为主，避免暖色。
```

### 1.6 渡劫雷云（Boss · data-scene 6）
```
天地级大场面低角度仰视。巨大漩涡状雷云压顶，云缝中紫电吞吐，山巅一个灰袍少年剪影
独立于刻满符文的石碑前（剪影即可，不画五官），雨丝斜落，远处山道上一排人群剪影仰头观望。
氛围：天地之威下的孤身一搏。主色：墨黑+紫电+一线金光。
```

### 1.7 封面（scene 0）
```
史诗起笔感。云海之上：古朴山门与层叠远山浸在破晓霞光中，云海翻涌铺满中景，
```

```
远山镀金、雾气将散。氛围：释然、天地回甘。主色：暖金+澄澈青白。
```

## 4. 出图参数与命名

- 场景：16:9；导出 WebP/PNG，单张 ≤300KB，先出 2-3 张候选挑 1 张。
- 立绘：1:1（512×512 视工具上限）；有文字残留用 Photopea 擦除或重生成。
- 命名与存放：
  - 场景 → `assets/scenes/lv1-book.webp`（沿用现有命名，lv2-ranch / lv3-gate / lv4-fenwen / lv5-valley / boss-thunder / cover / finale）
  - 战斗背景 → `assets/battles/battle-bg.webp`
  - 立绘 → `assets/portraits/<说话人>.png`（林慕/林韬/周显/章管事/一名围观弟子等）
- 放入后告诉我，我会更新 CSS 引用 + validate 存在性校验 + 目验清单。

## 5. 提醒

- 即梦/通义对“无文字”偶有失手：生成后检查，带字的图不要直接用。
- 透明底立绘多数工具不支持：可先深底出图，再用 Photopea/剪映抠图导出 PNG。
- AI 像素图通常“参考可看、直接放大就糊”：最终 16×16 帧仍需 LibreSprite 人工精修（管线已就绪）。
