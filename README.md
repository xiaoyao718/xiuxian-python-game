# 修仙学 Python · 仓绝大陆（第一卷）

> **当前版本：v1.1 动态演出版（代号：山鸣谷应）**
> 场景会呼吸、答题有演出、灵宠以练促养——在 MVP v1.0 之上新增动态场景、山河路线图、
> 灵宠养成与灵器行囊，纯静态零构建，双击 `index.html` 即可游玩。
> 在线试玩：https://xiaoyao718.github.io/xiuxian-python-game/
> （GitHub Pages，每次推送后约 1 分钟自动生效）

一个面向 0 基础学习者的 Python 剧情闯关网页游戏：随主角林慕在仓绝大陆上，
从 `print` 一路修到 `for`，最后亲手修正法诀渡过筑基天劫。学习内容与玩法闭环全部
在浏览器内完成（运行 Python 需要联网加载 Skulpt；音效为 WebAudio 实时合成，
不需要任何音频文件）。

## 本地运行

方式一：直接双击 `index.html`。

方式二：项目目录起静态服务：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000。

说明：离线可完整游玩剧情与答题；仅「▶ 运行」需要联网加载 Skulpt（会自动降级）。

## 如何加关卡 / 新题型

只改 `js/data.js`，向 `levels` 数组追加新对象即可，`game.js` 不需要动：

```js
{
  id: "lv6",              // 必须全局唯一（校验脚本会查）
  kind: "lesson",         // 或 "boss"
  chapter: "第六章",
  title: "章节名",
  stageLabel: "境界名",    // 与 D.realms 对应
  story: [...],
  lesson: { name, intro, points: [...], example: { code, output } },
  quest: [ { who, text }, { q: 0 }, ... ],
  questions: [ { q, options, answer, hint, explain, cheer } ],
  quizExtra: [ ... ],
  outro: [...]
}
```

新灵宠/新题型同理：`pets`、`petQuests`（每宠三组每组 ≥4 题）、`artifacts`
均为顶层纯新增字段。补全题示例：

```js
{
  kind: "fill",
  q: "题干",
  code: "print(__1__, __2__)",   // __n__ 占位
  slots: [ ["\"林慕\"", "林慕"], ["18", "\"18\""] ],
  answer: [0, 0]
}
```

加完跑一遍校验：

```bash
node scripts/validate-data.js
```

## 第二卷 · 字海拾遗（第一幕：字符串篇）

筑基初成后，林慕在宗门旧卷中接到一段被人为篡改的传讯。仙典引导他以字符串法诀还原线索：先从残简中读出坐标（索引与 `len()`），再截取密令碎片（切片），继而清除杂痕、辨认暗语（`strip()` / `replace()` / `find()`）。最终，旧渡口石碑下的任务簿揭示三年前云水城任务另有隐情，为下一幕“把多条线索收拢起来”埋下伏笔。

当前已上线五章：

- 「传讯残简」：索引与 `len()`
- 「截取灵笺」：切片
- 「灵笺辨伪」：`strip()` / `replace()` / `find()`
- 「渡口密令」：字符串综合试炼

- 「遗簿名录」：列表创建、索引与 `append()`；石匣中的多张残片由此被收拢为可继续查证的名录。

第二卷采用“见闻段 → 当下行动 → 后续场景”的节奏：仙典只在角色确实需要时给出短札记；传讯阁的带新人、休沐下山、渡口饮茶、夜航留名录等段落不附题目，用来推进人物与行程，而不是把剧情写成连续教学任务。

成就印章 UI 仍暂缓；数据层已预留 `achievements` 扩展位与 `App.sfx("seal")` 音效钩子。
