# 角色立绘目录（预留）

把插画放进本目录即可自动生效，命名规则与对话中的说话人完全一致：

```text
assets/portraits/林慕.svg
assets/portraits/仙典.svg
assets/portraits/周显.svg
assets/portraits/林韬.svg
assets/portraits/章管事.svg
assets/portraits/监考执事.svg
assets/portraits/一名围观弟子.svg
assets/portraits/一名杂役弟子.svg
```

规格：512×512、透明底、墨金朱风格（墨色剪影为主体、金色勾线点睛）。
插画加载后会盖在对话左侧立绘槽的占位朱印上方；缺失时占位印自动兜底，无布局抖动。
「旁白」不显示立绘槽。
